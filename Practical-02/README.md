# Practical 2 — Semantic HTML5 Pages with Accessibility-Ready Structure

**Subject:** ITUE203 Web Development Frameworks  
**CO Mapping:** CO1, CO2

## Objective

Develop static HTML5 skeletons for all StudentHub pages using semantic tags and accessibility-friendly structure.

## Pages Developed (11)

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Landing page with hero, features, announcements |
| About | `about.html` | Mission, institution info, team |
| Register | `register.html` | Student registration form |
| Login | `login.html` | Login form |
| Dashboard | `dashboard.html` | Student dashboard overview |
| Events | `events.html` | Campus events listing |
| Profile | `profile.html` | Student profile page |
| Contact | `contact.html` | Contact form |
| Admin | `admin.html` | Admin panel |
| FAQ | `faq.html` | Frequently asked questions |
| Feedback | `feedback.html` | Feedback form |

## Semantic Tags Used

`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<h1>`–`<h3>`, `<ul>`, `<form>`, `<label>`, `<fieldset>`

## Accessibility Features

- Skip-to-content link on every page
- `aria-label` on nav and sections
- `aria-labelledby` linking headings to sections
- `alt` text placeholders on all images
- Breadcrumb navigation
- Semantic form labels linked to inputs

## Tools Used

VS Code, HTML5, Chrome DevTools
