# Practical 3 — Responsive UI Design using CSS Grid, Flexbox, and Media Queries

**Subject:** ITUE203 Web Development Frameworks  
**CO Mapping:** CO2

## Objective

Style and make all StudentHub pages fully responsive using CSS3 features including CSS Grid, Flexbox, and media queries. Add a hamburger menu for mobile navigation and ensure visual consistency across mobile, tablet, and desktop viewports.

## Key CSS Features Used

| Feature | Usage |
|---------|-------|
| CSS Grid | Card layouts, stats grid, footer sections |
| Flexbox | Header, navigation, hero section, form layout, sidebar layout |
| Media Queries | Breakpoints at 480px, 768px, 1024px |
| CSS Custom Properties | Design tokens for colors, spacing, radius |
| CSS Transitions | Hover effects, menu animation, button interactions |
| Hamburger Menu | Mobile-first responsive navigation toggle |

## Responsive Breakpoints

- **Mobile:** ≤ 480px — single column, hamburger menu, stacked layout
- **Tablet:** 481px – 768px — two-column grid, condensed nav
- **Desktop:** 769px+ — full layout, multi-column grid, visible nav
