# Practical 1 — Project Initiation, Requirement Analysis, Sitemap, Wireframe & GitHub Setup

**Subject:** ITUE203 Web Development Frameworks  
**CO Mapping:** CO1

## Objective

Initiate the semester-long StudentHub portal by identifying the problem scope, user roles, key modules, navigation flow, and minimum 10 pages. Create a sitemap, low-fidelity wireframe, project folder structure, README, and GitHub repository.

## Deliverables

| File | Description |
|------|-------------|
| `sitemap.xml` | XML sitemap listing all portal pages and their relationships |
| `sitemap.html` | Visual HTML sitemap showing page hierarchy |
| `wireframe.txt` | Low-fidelity wireframes for key pages (Home, Register) |

## Key Pages Identified (10+)

1. Home (`index.html`)
2. About (`about.html`)
3. Register (`register.html`)
4. Login (`login.html`)
5. Dashboard (`dashboard.html`)
6. Events (`events.html`)
7. Profile (`profile.html`)
8. Contact (`contact.html`)
9. Admin (`admin.html`)
10. FAQ (`faq.html`)
11. Feedback (`feedback.html`)

## User Roles

- **Student** — View portal, register, manage profile, view events
- **Admin** — Manage students, events, and portal content

## Tools Used

VS Code, Git, GitHub
